# Cena 3D em um pedido (a skill do vídeo da Avenida Paulista)

A skill está na pasta [`cena-3d-um-pedido`](cena-3d-um-pedido). Ela faz o Claude montar uma cena 3D que abre no navegador (lugar, clima, movimento e som) a partir de uma frase curta, num arquivo só, sem instalar nada.

## Instalar no Claude Code
Copia a pasta `cena-3d-um-pedido` para dentro de `~/.claude/skills/` no teu computador e abre uma conversa nova.

## Usar
Pede, por exemplo: `monta uma cena 3D da Avenida Paulista, de noite e chovendo`. O Claude entrega um arquivo `.html`; abre no navegador.
