# Os 3 melhores mods do Claude (+10 ideias)

Mod é uma mudança que tu pedes ao próprio Claude e ele constrói: um botão, um aviso, um filtro. Funciona na aba **Code** do app do Claude no computador (precisa da assinatura paga).

## Como criar um mod
1. Abre o app do Claude no computador e vai na aba **Code**.
2. Cola um dos pedidos abaixo e envia.
3. O Claude escreve o mod e pergunta se pode ligar os mods da sessão. Aceita.
4. Testa. Se algo não ficar como tu queres, diz o que mudar: ele corrige.

## 1. Lembra disso
```
Cria um mod do Claude com um botão "Lembra disso" acima da caixa de mensagem. Quando eu apertar, ele lê o que eu escrevi na caixa, separa em regras (como o Claude deve trabalhar) e notas (fatos sobre mim e meu negócio), me mostra o que achou e, se eu confirmar, guarda. O que foi guardado deve acompanhar todas as minhas mensagens seguintes.
```

## 2. Explica comando
```
Cria um mod do Claude que, toda vez que o Claude pedir permissão para rodar um comando, mostra embaixo do pedido uma frase em português claro dizendo o que o comando faz, com o nível de risco: verde (só lê), amarelo (muda algo) ou vermelho (apaga ou não dá para desfazer).
```

## 3. Guarda de privacidade
```
Cria um mod do Claude com um botão "Privacidade" acima da caixa de mensagem. Quando eu apertar, ele confere o que escrevi e lista o que o Claude não precisa saber (senha, número de conta, endereço, nome completo de cliente, documento). Se eu confirmar, troca cada trecho por uma etiqueta como [CLIENTE_1] antes de eu enviar.
```

## Mais 10 ideias (ainda não testei estas)
- **Barra de Meta:** uma faixa que mostra o objetivo da conversa e quanto falta.
- **Para de Enrolar:** avisa quando o Claude repete a mesma tentativa sem avançar.
- **Pedido Vago:** antes de enviar, avisa se o teu pedido está genérico e sugere o que detalhar.
- **Terminou Mesmo?:** antes de o Claude dizer "pronto", confere se ele testou o que fez.
- **Minhas Tarefas:** um painel ao lado com a lista do que está pendente.
- **Me Ajuda a Decidir:** um botão que transforma a dúvida em duas opções com prós e contras.
- **Sininho:** toca um som quando o Claude termina uma tarefa longa.
- **Modo Gravação:** esconde nomes e dados da tela enquanto tu gravas vídeo.
- **Retrospectiva:** no fim do dia, resume o que foi feito.
- **Fliperama:** um joguinho para passar o tempo enquanto ele trabalha.

## O que eu testei e o que não testei
- **Testado:** construí os três primeiros mods no Claude Code e eles funcionam aqui. O Guarda de Privacidade eu vi trocando uma senha por [SENHA_1] antes de a mensagem sair.
- **Atenção:** eu construí acompanhando e pedindo correções, não com um pedido só. Os textos acima são o ponto de partida; é normal precisar de um ou dois ajustes.
- **Não testado:** as dez ideias da lista.
