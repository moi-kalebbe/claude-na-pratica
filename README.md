# Claude na prática

Os materiais que eu mando para quem comenta nos meus vídeos do Instagram ([@moiseskalebbe](https://www.instagram.com/moiseskalebbe/)). Cada pasta é a entrega de uma palavra:

| Palavra | O que tem |
|---|---|
| [FILME](filme) | a skill que faz filme só com código e os 3 pedidos de propaganda |
| [ESTILO](estilo) | os 10 estilos de animação da mesma cena, com os pedidos prontos |
| [PROMPT](prompt) | o botão Prompt Master, que reescreve o teu pedido antes de enviar |
| [MARKETING](marketing) | o time de marketing grátis pro Claude e o passo a passo |
| [MOD](mod) | os 3 prompts dos mods e mais 10 ideias de mods do Claude |
| [FABLE](fable) | a skill que monta uma cena 3D (como a Avenida Paulista) com um pedido só |
| [PEIXINHO](peixinho) | o método do elefante e do peixinho, do Google, e como usar |
| [SOM](som) | os 3 plugins grátis que dão som de verdade ao Claude, o pedido que instala e o guia |
| [COPIA](copia) | o rea-video, que desmonta qualquer vídeo cena por cena pro Claude copiar o formato, e o pedido que instala |
| [FUNCIONARIO](funcionario) | o kit das 10 peças do funcionário de IA (CLAUDE.md, skill, hook, tarefa agendada...), com os arquivos prontos |

Tudo aqui é grátis. Toda semana eu testo uma IA nova e a entrega dela entra aqui.
